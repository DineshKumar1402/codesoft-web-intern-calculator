# Calculator Application

This is a simple calculator web application built using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations like addition, subtraction, multiplication, and division.

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- Responsive design, adapting to different screen sizes.
- A clean and intuitive user interface with large buttons and an easy-to-read display.

## Technologies Used
- **HTML**: Used to structure the calculator and define the layout.
- **CSS**: Used for styling the layout, including colors, font sizes, and responsive design.
- **JavaScript**: Provides functionality for calculator operations, including evaluating the expressions typed by the user.

## File Structure
```
/project-directory
    /index.html          (HTML code for the calculator application)
    /style.css           (CSS code for styling the calculator)
```

## How to Use

1. Open the `index.html` file in any web browser.
2. Use the calculator by clicking the buttons on the screen.
   - The numbers (0-9) and operators (+, -, *, /) can be clicked to input expressions into the display.
   - Press the `C` button to clear the display.
   - Press the `=` button to evaluate the expression and show the result.
3. The calculator automatically adjusts for different screen sizes and will resize buttons accordingly.

## Media Queries
The CSS includes media queries to make the calculator responsive across different device widths:
- For **small screens** (max-width: 600px), the font size and button size are adjusted for better visibility and usability.
- For **medium screens** (601px to 1024px), the button and text sizes are slightly increased.
- For **larger screens** (min-width: 1025px), the button and text sizes are optimized for desktop view.
